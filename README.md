# Last Ai Coding

مساعد برمجة بالذكاء الاصطناعي يعمل من الطرفية، ويتصل بنماذج مثل DeepSeek وClaude وGPT أو نماذج محلية.

مبني على Aider (https://github.com/Aider-AI/aider) وهو مرخّص بـ Apache-2.0.

## التثبيت
    pip install aider-install
    aider-install

## الاستخدام
    aider --model deepseek --api-key deepseek=YOUR_KEY

المشروع الأصلي: Aider-AI/aider. انظر LICENSE.txt وNOTICE، والوثائق الأصلية في README.aider.md.
